Project Spotlight

FPGA + MICROCONTROLLER ARCHITECTURE

Dual-Hardware Secure Locking System

An air-gapped embedded security system that decouples wireless RF communication from hardware execution logic. The Tang Nano 20K FPGA acts as the isolated Hardware Root of Trust, executing a 16-bit LFSR rolling code engine that produces 65,535 non-repeating dynamic OTP authentication keys.
