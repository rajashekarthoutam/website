# Rajashekar Thoutam - Hardware & Embedded Systems Engineer

🌐 **Live Website**: [https://rajashekarthoutam.in/](https://rajashekarthoutam.in/)  
🌐 **GitHub Pages Mirror**: [https://rajashekarthoutam.github.io/website/](https://rajashekarthoutam.github.io/website/)

Official WebGL engineering portfolio and interactive showcase of **Rajashekar Thoutam**, specializing in FPGA Logic, Verilog HDL, Hardware Root of Trust, and Air-Gapped Embedded Systems.

## 🚀 Key Features
- **Interactive Three.js 3D FPGA Core**: Real-time 3D silicon die rendered in Electric Emerald (`#10b981`) and Violet (`#8b5cf6`) with orbiting logic buses.
- **Web Audio Synthesizer**: Procedural acoustic feedback for button interactions and FSM unlock sequences.
- **Floating Capsule Pill Navigation**: Smooth sliding active pill indicator (David Heckhoff-inspired).
- **Tang Nano 20K LFSR & FSM Simulator**: Interactive algorithmic simulator calculating 16-bit dynamic OTP tokens and driving a Verilog Finite State Machine.
- **Featured Project Spotlight**: Dual-Hardware Air-Gapped Secure Locking System with interactive architecture modal.
