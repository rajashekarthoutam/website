# Personal Portfolio & WebGL Engineering Showcase

🌐 **Live Website**: [https://rajashekarthoutam.in/](https://rajashekarthoutam.in/)  
🌐 **GitHub Pages Mirror**: [https://rajashekarthoutam.github.io/website/](https://rajashekarthoutam.github.io/website/)

An interactive 3D WebGL portfolio and developer showcase inspired by modern creative web architecture.

## 🚀 Key Features
- **Interactive Three.js 3D Core**: Holographic silicon die with mouse-parallax reactivity.
- **Web Audio Synthesizer**: Procedural acoustic feedback with volume wave toggle.
- **Floating Capsule Pill Navigation**: Smooth sliding active pill indicator.
- **Holographic Callouts & Angled Banners**: Tech HUD annotations and modern typography.
- **Interactive Simulators & Terminal**: Embedded algorithmic pipeline and CLI developer shell.
- **Clean Responsive Architecture**: Pure HTML5, Vanilla CSS, and JavaScript.
