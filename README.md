# Thoutam Rajashekar - Personal Portfolio & Resume Website

🌐 **Live Website**: [https://rajashekarthoutam.github.io/website/](https://rajashekarthoutam.github.io/website/)

Official personal portfolio and technical showcase of **Thoutam Rajashekar** — Electronics & Communication Engineering Undergraduate, Hardware & Embedded Systems Specialist.

## 🚀 Features
- **Interactive Particle Matrix**: Canvas-powered background animation.
- **Hardware & Engineering Showcase**: Tang Nano 20K FPGA Dual-Hardware Secure Lock, Arduino Vehicle Safety System, V2G Infrastructure, and Medha Servo Drives LTC assembly.
- **FSM & RTL Logic Inspector**: Interactive visual state machine & hardware telemetry demonstration.
- **Dynamic Category Filtering**: Filter across FPGA, Embedded Systems, IoT, and Power Electronics.
- **Technical Resume Modal**: Instant viewing of qualifications, industrial experience, and technical competencies.
- **Modern Responsive Design**: Optimized for mobile, tablet, and high-DPI desktop screens.

## 🛠️ Tech Stack
- Pure HTML5, CSS3, and Vanilla JavaScript (zero heavy framework overhead, blazing fast load times).
- Font Awesome 6 for engineering iconography.
- Hosted on GitHub Pages with HTTPS.
